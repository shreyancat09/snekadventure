Snek Adventure-
A simple Pygame arcade game made for Hack Club. You dodge falling obstacles, keep your streak alive, and try to set a high score.

Additional Features-
High Score Persistence: Saves your highest score locally to highscore.txt so your record stays saved across sessions :)
Dynamic Difficulty Scaling: Obstacle drop speed increase gradually based on your score, making the challenge harder,the longer you survive....

Controls
W / A / S / D or Arrow Keys - Move
SPACE - Start Game (from menu)
R - Restart (after Game Over)

How to Run
From Source--
pip install pygame-ce
python main.py

or......by exe file--
You can run the compiled version directly without installing Python:
Navigate to the dist/ directory and launch main.exe.
I have also made a release where you can download it.
